# Frontend README for Poker Analytics App

# Poker Analytics App - Frontend

This is the frontend part of the Poker Analytics App, built with React and TypeScript. The application allows users to submit PokerNow Game IDs and fetch related data from the backend.

## Getting Started

To get started with the frontend application, follow these steps:

### Prerequisites

Make sure you have the following installed on your machine:

- Node.js (version 14 or higher)
- npm (Node Package Manager)

### Installation

1. Navigate to the frontend directory:

   ```bash
   cd poker-analytics-app/frontend
   ```

2. Install the dependencies:

   ```bash
   npm install
   ```

### Running the Application

To start the development server, run:

```bash
npm start
```

This will start the application on `http://localhost:3000`.

### Building for Production

To create a production build of the application, run:

```bash
npm run build
```

The build artifacts will be stored in the `build` directory.

## Features

- Submit PokerNow Game IDs through a user-friendly form.
- Fetch and display game-related data using React Query.
- Responsive design for optimal viewing on various devices.
